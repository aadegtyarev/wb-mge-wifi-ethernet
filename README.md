# WB-MGE v3: Wi-Fi → Ethernet

Экспериментальная прошивка для Wiren Board WB-MGE v.3: подключает **один** Ethernet-клиент к сети Wi-Fi 2,4 ГГц без IP NAT и без изменения настроек роутера. Основана на примере Espressif `sta2eth` для ESP-IDF 5.5.2.

> **Статус:** подключение к Wi-Fi, короткое нажатие для переключения точек и индикация Status/Wi-Fi проверены на одном устройстве. Сквозной Ethernet-мост и автоматический переход на другую точку пока не проверены. Проект не готов к публикации как стабильный продукт.

## Ограничения и безопасность

- Это **не универсальный прозрачный L2-мост**: прошивка подменяет MAC-адреса и рассчитана на один клиент IPv4. Для определения MAC клиента используются DHCP Discover/Request или Ethernet/IPv4 ARP. Статический IP, IPv6, VLAN, много клиентов и произвольные протоколы не заявлены как работающие.
- При настройке WB-MGE создаёт **открытую сеть без пароля**; страница использует незашифрованный HTTP. Любой находящийся рядом может подключиться, изменить настройки или перехватить пароль домашней сети. Настраивайте только в доверенном окружении. Точка закрывается после сохранения или через пять минут.
- Пароль домашней Wi-Fi-сети хранится во flash. Полная резервная копия flash может содержать пароли и другие конфиденциальные данные; не публикуйте её.
- При смене точки происходит разрыв соединения. SSID и пароль у всех точек сети должны совпадать. Для сети с паролем используется порог безопасности ESP-IDF не ниже WPA2; старые WEP и WPA-only не поддерживаются текущими настройками.
- Эта прошивка заменяет заводские функции RS-485/Modbus. Экспериментальная прошивка и возврат к штатной могут потребовать перепрошивки через USB.

## Настройка

При первом запуске или после удержания кнопки Config более двух секунд создаётся сеть `MGE-Setup-XXXXXX`. Подключитесь к ней, откройте `http://192.168.4.1/`, введите SSID и пароль сети 2,4 ГГц. Поддерживаются SSID до 32 байт, пустой пароль для открытой сети, пароль длиной 8–63 байта или 64 шестнадцатеричных символа PSK. После сохранения устройство перезагружается. В режиме настройки мост не работает; если закрыть настройку по тайм-ауту без изменения ранее сохранённых параметров, устройство вернётся к ним. Если страница не открывается автоматически, откройте указанный адрес вручную.

Короткое нажатие Config запускает поиск точек с тем же SSID и переключение на следующий BSSID. Если выбранная точка недоступна, предусмотрена попытка подключения к другой точке той же сети; этот сценарий ещё нужно проверить на устройстве.

| Индикатор | Значение |
| --- | --- |
| Status | Медленно мигает при работе, быстро в режиме настройки. |
| Wi-Fi | Горит при подключении; мигает при поиске или переподключении. При ручном переключении мигание длится не менее двух секунд, даже если поиск завершился быстро. |
| Ethernet | Горит при наличии линка. |

Диагностика и результаты работы моста доступны через последовательный порт. Веб-интерфейса для постоянного контроля нет.

## Сборка в Docker

Нужен работающий Docker с доступом к образу `espressif/idf:v5.5.2`. В корне проекта:

```sh
docker run --rm -e HOME=/tmp -v "$PWD:/project" -w /project \
  espressif/idf:v5.5.2 idf.py build
```

Результат: `build/sta_to_eth.bin`, загрузчик и таблица разделов в `build/`. Этот способ проверен с rootless Docker; при другом режиме Docker может понадобиться настройка владельца файлов. Сборка не записывает прошивку в устройство.

Проверить ввод параметров Wi-Fi, выбор BSSID, разбор DHCP и часть преобразований кадров под ASan/UBSan и собрать проект можно командой `./scripts/check.sh`. Это не заменяет проверку моста и устройства на реальном оборудовании.

Перед экспериментами сохраните полную копию flash и проверьте способ восстановления. Инструкции производителя: [своя прошивка и GPIO](https://wirenboard.wiki/reference/wb-mge-v3-diy/). Восстановление резервной копии этого проекта ещё не проверено.

### Запись файлов релиза

Экспериментальный релиз содержит три `.bin` и `SHA256SUMS`. Скачайте их в отдельную папку, проверьте `sha256sum -c SHA256SUMS`, подключите WB-MGE через USB и при необходимости замените `/dev/ttyACM0` на свой порт. Из папки с файлами:

```sh
docker run --rm --device=/dev/ttyACM0:/dev/ttyACM0 -v "$PWD:/firmware:ro" -w /firmware \
  espressif/idf:v5.5.2 esptool.py --chip esp32 --port /dev/ttyACM0 --baud 460800 \
  write_flash --flash_mode dio --flash_freq 40m --flash_size 4MB \
  0x1000 bootloader.bin 0x8000 partition-table.bin 0x10000 sta_to_eth.bin
```

**Запись заменяет загрузчик, таблицу разделов и приложение.** Команда не стирает область NVS `0x9000–0xefff`; её прежнее содержимое может быть несовместимо с новой таблицей разделов. Если NVS не инициализируется, прошивка не станет стирать её автоматически. Прежде чем отдельно стирать или восстанавливать flash, сохраните резервную копию: в NVS могут быть настройки и пароли. Не записывайте эти файлы без резервной копии или на устройство, чей тип не подтверждён.
